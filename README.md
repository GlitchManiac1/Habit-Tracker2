Hello. This is my first official project on GitHub. It's a command-line tracker for logging daily habits and viewing your progress.
## Habit Tracker
## Before you can run the script make sure:
- You have python 3 installed

## If you do, run the following in the terminal line by line. As in press enter after each line
1. `git clone https://github.com/GlitchManiac1/Habit-Tracker2.git`
2. `cd Habit-Tracker2`
3. `python tracker2.py`
